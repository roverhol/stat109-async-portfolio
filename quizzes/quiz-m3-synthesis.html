Section A — Five-number summary and boxplots (Read 1)

A1. Compute five-number summary

Data (sorted): \(2, 5, 7, 8, 10, 12, 15, 18, 22, 30\). Compute the five-number summary (min, \(Q_1\), median, \(Q_3\), max).

A2. IQR and outlier fence

A dataset has five-number summary min \(= 2\), \(Q_1 = 7.5\), median \(= 11\), \(Q_3 = 16.5\), max \(= 30\). Compute the IQR and the upper outlier fence (\(Q_3 + 1.5 \times \text{IQR}\)).

A3. Compare groups from boxplots

Two groups have boxplots: Group A median=25, \(Q_1=18\), \(Q_3=32\); Group B median=40, \(Q_1=35\), \(Q_3=45\). Which group has higher typical values? Which has more spread?

A4. R code for grouped boxplot

Write the ggplot2 call for boxplots of body_mass_g grouped by species in the penguins dataset.

A5. group_by + summarize in R

Write the pipeline that computes median and IQR of body_mass_g for each species.

Section B — Scatterplot description (Read 2 §2)

B1. Describe a scatterplot

A scatterplot of bill_length_mm vs flipper_length_mm shows points trending upward in a roughly straight band. Describe the association.

B2. Negative association

A scatterplot shows higher values of \(x\) paired with lower values of \(y\), with points scattered loosely. Describe the association.

B3. No association

A scatterplot shows no discernible trend — points form a cloud with no slope. Describe the association.

B4. R code for scatterplot

Write the ggplot2 call for a scatterplot of bill_length_mm (x) vs flipper_length_mm (y).

B5. Color points by group

How would you modify the scatterplot to color points by species?

Section C — Two-way tables and proportions (Read 2 §3)

C1. Build a two-way table in R

Write the tidyverse pipeline that counts the number of penguins of each species on each island.

C2. Compute row proportions

Two-way count table (species × island) has row totals: Adelie=152, Chinstrap=68, Gentoo=124. Adelie on Biscoe=44. What is the row proportion of Adelie on Biscoe?

C3. Compute column proportions

Two-way count table (species × island): Biscoe column total=168 penguins, and Gentoo on Biscoe=124. What is the column proportion of Gentoo among Biscoe penguins?

C4. Stacked bar chart in R

Write the ggplot2 call for a 100% stacked bar of island (x) with species fill.

C5. pivot_wider usage

After penguins %>% count(species, island), you want a wide table with species as rows and islands as columns. Which function converts it?

Section D — Choosing the right graph/summary (integration)

D1. Match to variable types

Match each scenario to the correct graph:

  1. Penguin mass by species
  2. Bill length vs flipper length
  3. Species distribution on each island
  4. Distribution of flipper lengths alone

D2. When group_by before summarize

You have penguins and want the mean flipper length for each sex. Write the pipeline.

D3. filter before plot

You want a scatterplot of only Adelie penguins. What step comes before ggplot?

D4. na.rm in summaries

Why is na.rm = TRUE often needed inside mean() or median()?

Section E — Project 3 workflow (demo lab R patterns)

E1. Load data from URL

You want to load a CSV file from a URL in R. Which function do you use, and where does the URL go?

E2. Recode a variable

Column sex has values 1 and 2 (numeric). You want 'male' and 'female'. Which tidyverse function and how?

E3. Handling missing values before plot

Before making a scatterplot of bill_length_mm vs flipper_length_mm, how do you drop rows with NA in either variable?

Section F — Graph integration (verbal · no image)

H2. filter()

H3. select()

H4. mutate()

H5. count()

H7. summarize()
