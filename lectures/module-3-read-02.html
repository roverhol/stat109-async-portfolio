Why two categorical variables together

Each observation has a level of variable A (e.g. species) and a level of variable B (e.g. habitat). We summarize how the combinations co-occur: counts in each cell of a table, then graphs can show these counts or proportions at a glance.

Small example by hand (two binary variables)

Setting. Birds counted in two habitats: Urban or Rural. Species recorded as Robin or Sparrow (ignore other species here).

Counts:

Urban Rural Row total
Robin 8 2 10
Sparrow 4 6 10
Column total 12 8 20 = grand total \(N\)

So there are 20 birds. The joint count in each cell is a count of birds with that (species, habitat) pair.

Joint proportions (of the grand total)

Each cell count divided by \(N = 20\) answers: What fraction of all birds fall in this cell?

  • Robin & Urban: \(8/20 = 0.40\)
  • Robin & Rural: \(2/20 = 0.10\)
  • Sparrow & Urban: \(4/20 = 0.20\)
  • Sparrow & Rural: \(6/20 = 0.30\)

Check: \(0.40 + 0.10 + 0.20 + 0.30 = 1\).

Row proportions (conditional on species)

Within each species, divide by that row’s total (10). Answers: Among Robins only, what fraction were Urban vs Rural? (and similarly for Sparrows.)

Robin: Urban \(8/10 = 0.80\), Rural \(2/10 = 0.20\).

Sparrow: Urban \(4/10 = 0.40\), Rural \(6/10 = 0.60\).

Each row sums to \(1\).

Column proportions (conditional on habitat)

Within each habitat, divide by that column’s total. Answers: Among Urban birds, what fraction were Robin vs Sparrow?

Urban: Robin \(8/12 \approx 0.67\), Sparrow \(4/12 \approx 0.33\) (column total 12).

Rural: Robin \(2/8 = 0.25\), Sparrow \(6/8 = 0.75\) (column total 8).

Each column sums to \(1\).

Note: The same four counts support three different stories depending on whether you normalize by everything (joint or “grand”), by rows (species), or by columns (habitat). Be explicit about which denominator you use when you write a sentence or label a plot.

Example 1: The bird table in R’s tidyverse

We store one row per bird: variables species and habitat.

Code 
if (!requireNamespace("tidyverse", quietly = TRUE)) {
  install.packages("tidyverse", repos = "https://cloud.r-project.org")
}

library(tidyverse)

birds <- tibble(
  species = c(rep("Robin", 10), rep("Sparrow", 10)),
  habitat = c(rep(c("Urban", "Rural"), c(8, 2)), rep(c("Urban", "Rural"), c(4, 6)))
) |>
  mutate(
    species = factor(species, levels = c("Robin", "Sparrow")),
    habitat = factor(habitat, levels = c("Urban", "Rural"))
  )

Stacked bar chart of counts

Bars show species; segments show habitat; height of each segment is the cell count.

  labs(

    x = NULL,
    y = "Count",
    fill = "Habitat"

Stacked bar chart with 100% within each species (row proportions)

position = "fill" stretches each bar to height 1; segment heights match row proportions (prop_row). Good for comparing habitat mix between species when raw counts differ.

NoteFrom this sample to a population — inference reference note

Described here: counts and row/column proportions in a two-way table. Population parameter: for a 2×2 table, the difference in population proportions \(p_1 - p_2\); more generally, whether the two categorical variables are associated (not independent) in the population.

Two groups, one proportion each (2×2): two-proportion test. If you want to compare two population proportions (\(H_0: p_1 = p_2\)) or estimate their difference, then — after checking conditions (independent observations; expected cell counts large enough, about \(\ge 5\)) — use the two-proportion test, which returns a confidence interval for \(p_1 - p_2\) and a p-value.

Any size table: chi-square test of independence. More generally, test whether the two categorical variables are associated,

\[ H_0: \text{the two variables are independent} \quad\text{vs.}\quad H_a: \text{they are associated}, \]

using the chi-square statistic, which compares the observed cell counts to the counts you’d expect if the variables were independent,

\[ \chi^2 = \sum_{\text{cells}} \frac{(O - E)^2}{E}, \qquad E = \frac{(\text{row total})(\text{column total})}{N}. \]

If the variables are truly independent, \(O\) and \(E\) are close and \(\chi^2\) is small; a large \(\chi^2\) (small p-value) is evidence of association. The reference distribution has \(\text{df} = (r-1)(c-1)\) for an \(r \times c\) table. For a 2×2 table the chi-square test and the two-proportion test answer the same question. Let software do the work:

prop.test(c(x1, x2), c(n1, n2))   # 2x2: CI for p1 - p2 and test
chisq.test(table(var1, var2))     # general test of independence (any size table)

Both are introduced in Module 4 (two-proportion and chi-square tests).

Why two numerical variables together

When both variables are numerical, we often ask how one changes with the other: does taller vegetation go with wetter soil? Does leaf nitrogen track soil nitrate? A scatterplot puts one variable on the horizontal axis and one on the vertical axis; each point is one observational unit (a tree, a nest, a transect).

Describing a scatterplot in words

Read the cloud of points as a whole.

Form (shape). Is the trend roughly a straight line (linear), bent (curved / nonlinear), split into clusters, or no clear pattern?

Direction. As \(x\) increases, does \(y\) tend to increase (positive association), decrease (negative association), or show no consistent up-or-down trend?

Strength. How tightly do points follow the trend in the form? Strong: points closely hug a line or curve. Moderate: signal is visible but some random scatter above and below is noticeable. Weak: only a faint drift. None: no useful trend (uniform random scatter around a horizontal band).

These labels are judgment calls in practice; the point is to communicate what you see before moving to formal models.

Summary

For two numerical variables, a scatterplot in ggplot2 uses aes(x, y) and geom_point(). Describe what you see with form (linear vs curved vs none), direction (positive, negative, or none), and strength (strong through none).

Pearson correlation \(r\) (linear association)

When a scatterplot looks roughly linear, add a numerical summary of linear direction and strength: Pearson’s correlation coefficient \(r\).

Fact Detail
Range \(-1 \leq r \leq 1\) (unitless)
Sign \(r > 0\) positive direction; \(r < 0\) negative
Strength \(|r|\) near 1 = strong linear trend; near 0 = weak or none
When to use Form is approximately linear — not for strong curves or outliers

\[ r = \dfrac{\sum (x_i - \bar{x})(y_i - \bar{y})}{\sqrt{\sum (x_i - \bar{x})^2}\sqrt{\sum (y_i - \bar{y})^2}} \]

The numerator tracks whether \(x\) and \(y\) move together above/below their means; the denominator rescales so \(r\) stays between \(-1\) and \(1\).

WarningCorrelation describes linear association only

If the scatterplot is curved, \(r\) can be misleading (see Example 4 below). Always read the plot first; use \(r\) only when form is roughly linear.

## Why two categorical variables together

Each observation has a level of variable A (e.g. species) and a level of variable B (e.g. habitat). We summarize how the combinations co-occur: counts in each cell of a table, then graphs can show these counts or proportions at a glance.

## Small example by hand (two binary variables)

Setting. Birds counted in two habitats: Urban or Rural. Species recorded as Robin or Sparrow (ignore other species here).

Counts:

|              | Urban | Rural | Row total            |
|--------------|-------|-------|----------------------|
| Robin        | 8     | 2     | 10                   |
| Sparrow      | 4     | 6     | 10                   |
| Column total | 12    | 8     | 20 = grand total $N$ |

So there are 20 birds. The joint count in each cell is a count of birds with that (species, habitat) pair.

### Joint proportions (of the grand total)

Each cell count divided by $N = 20$ answers: *What fraction of all birds fall in this cell?*

-   Robin & Urban: $8/20 = 0.40$
-   Robin & Rural: $2/20 = 0.10$
-   Sparrow & Urban: $4/20 = 0.20$
-   Sparrow & Rural: $6/20 = 0.30$

Check: $0.40 + 0.10 + 0.20 + 0.30 = 1$.

### Row proportions (conditional on species)

Within each species, divide by that row’s total (10). Answers: *Among Robins only, what fraction were Urban vs Rural?* (and similarly for Sparrows.)

Robin: Urban $8/10 = 0.80$, Rural $2/10 = 0.20$.

Sparrow: Urban $4/10 = 0.40$, Rural $6/10 = 0.60$.

Each row sums to $1$.

### Column proportions (conditional on habitat)

Within each habitat, divide by that column’s total. Answers: *Among Urban birds, what fraction were Robin vs Sparrow?*

Urban: Robin $8/12 \approx 0.67$, Sparrow $4/12 \approx 0.33$ (column total 12).

Rural: Robin $2/8 = 0.25$, Sparrow $6/8 = 0.75$ (column total 8).

Each column sums to $1$.

Note: The same four counts support three different stories depending on whether you normalize by everything (joint or "grand"), by rows (species), or by columns (habitat). Be explicit about which denominator you use when you write a sentence or label a plot.

## From this sample to a population — inference reference note

**Described here:** counts and row/column proportions in a two-way table. **Population parameter:** for a 2×2 table, the difference in population proportions $p_1 - p_2$; more generally, whether the two categorical variables are **associated** (not independent) in the population.

**Two groups, one proportion each (2×2): two-proportion test.** If you want to **compare two population proportions** ($H_0: p_1 = p_2$) or estimate their difference, then — after checking conditions (independent observations; expected cell counts large enough, about $\ge 5$) — use the two-proportion test, which returns a confidence interval for $p_1 - p_2$ and a *p*-value.

**Any size table: chi-square test of independence.** More generally, test whether the two categorical variables are associated,

$$
H_0: \text{the two variables are independent} \quad\text{vs.}\quad H_a: \text{they are associated},
$$

using the chi-square statistic, which compares the **observed** cell counts to the counts you'd **expect** if the variables were independent,

$$
\chi^2 = \sum_{\text{cells}} \frac{(O - E)^2}{E}, \qquad E = \frac{(\text{row total})(\text{column total})}{N}.
$$

If the variables are truly independent, $O$ and $E$ are close and $\chi^2$ is small; a large $\chi^2$ (small *p*-value) is evidence of association. The reference distribution has $\text{df} = (r-1)(c-1)$ for an $r \times c$ table. For a 2×2 table the chi-square test and the two-proportion test answer the same question. Let software do the work:

``` r
prop.test(c(x1, x2), c(n1, n2))   # 2x2: CI for p1 - p2 and test
chisq.test(table(var1, var2))     # general test of independence (any size table)
```

Both are introduced in [Module 4](module-4-read-02) (two-proportion and chi-square tests).

## Why two numerical variables together

When both variables are numerical, we often ask how one changes with the other: does taller vegetation go with wetter soil? Does leaf nitrogen track soil nitrate? A scatterplot puts one variable on the horizontal axis and one on the vertical axis; each point is one observational unit (a tree, a nest, a transect).

------------------------------------------------------------------------

------------------------------------------------------------------------

## Describing a scatterplot in words

Read the cloud of points as a whole.

Form (shape). Is the trend roughly a straight line (linear), bent (curved / nonlinear), split into clusters, or no clear pattern?

Direction. As $x$ increases, does $y$ tend to increase (positive association), decrease (negative association), or show no consistent up-or-down trend?

Strength. How tightly do points follow the trend in the form? Strong: points closely hug a line or curve. Moderate: signal is visible but some random scatter above and below is noticeable. Weak: only a faint drift. None: no useful trend (uniform random scatter around a horizontal band).

These labels are judgment calls in practice; the point is to communicate what you see before moving to formal models.

## Pearson correlation $r$ (linear association)

When a scatterplot looks roughly linear, add a numerical summary of linear direction and strength: Pearson's correlation coefficient $r$.

| Fact | Detail |
|-------------------------------|-----------------------------------------|
| Range | $-1 \leq r \leq 1$ (unitless) |
| Sign | $r > 0$ positive direction; $r < 0$ negative |
| Strength | $|r|$ near 1 = strong linear trend; near 0 = weak or none |
| When to use | Form is approximately linear — not for strong curves or outliers |

$$
r = \dfrac{\sum (x_i - \bar{x})(y_i - \bar{y})}{\sqrt{\sum (x_i - \bar{x})^2}\sqrt{\sum (y_i - \bar{y})^2}}
$$

The numerator tracks whether $x$ and $y$ move together above/below their means; the denominator rescales so $r$ stays between $-1$ and $1$.

::: callout-warning
## Correlation describes linear association only

If the scatterplot is curved, $r$ can be misleading (see Example 4 below). Always read the plot first; use $r$ only when form is roughly linear.
:::
