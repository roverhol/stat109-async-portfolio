Code 
# Module 0 — baby-matching simulation (pattern)
set.seed(109)
mothers <- c(1, 2, 3, 4)
num_correct <- numeric(10000)
for (i in 1:10000) {
  babies <- sample(c(1, 2, 3, 4))
  num_correct[i] <- sum(babies == mothers)
}
mean(num_correct == 4)   # P(all 4 correct)
mean(num_correct == 0)   # P(none correct)

Module 1 — Conditional simulation

Task Code pattern
Build labeled pool balls <- rep(c("R", "W"), c(3, 3))
Draw without replacement sample(balls, size = 2, replace = FALSE)
Pre-allocate successes <- vector("numeric", 10000)
Record with if if (condition) { successes[k] <- 1 }
AND / OR in if if (a & b); if (a \| b)
Which replicates which(successes == 1)
Weighted sample sample(c("yes", "no"), n, replace = TRUE, prob = c(0.7, 0.3))
Joint probability mean(disease == 1 & test == 1)
Conditional from sim mean(disease == 1 & test == 1) / mean(test == 1)
Code 
balls <- rep(c("R", "W"), c(3, 3))
replicates <- 10000
successes <- vector("numeric", replicates)
set.seed(109)
for (k in 1:replicates) {
  draw <- sample(balls, 2, replace = FALSE)
  if (draw[1] == "W" & draw[2] == "R") successes[k] <- 1
}
mean(successes)

# Joint event
mean(child == 1 & gummy == 1)

Modules 3–5 — Analysis pipeline

Step Code idea Quick check
1 library(tidyverse) Packages load without errors
2 read_csv(...); glimpse(dat) Column names and types match Part 1
3 mutate(... factor(..., levels = ...)) Levels match your two groups / outcome categories
4 group_by + summarise and/or count Means/SDs if numerical; counts if categorical

Response type R command Notes

## Module 1 — Conditional simulation {#r-lab3}

| Task | Code pattern |
|------|----------------|
| Build labeled pool | `balls <- rep(c("R", "W"), c(3, 3))` |
| Draw without replacement | `sample(balls, size = 2, replace = FALSE)` |
| Pre-allocate | `successes <- vector("numeric", 10000)` |
| Record with `if` | `if (condition) { successes[k] <- 1 }` |
| AND / OR in `if` | `if (a & b)`; `if (a \| b)` |
| Which replicates | `which(successes == 1)` |
| Weighted sample | `sample(c("yes", "no"), n, replace = TRUE, prob = c(0.7, 0.3))` |
| Joint probability | `mean(disease == 1 & test == 1)` |
| Conditional from sim | `mean(disease == 1 & test == 1) / mean(test == 1)` |

```{r}
#| eval: false
balls <- rep(c("R", "W"), c(3, 3))
replicates <- 10000
successes <- vector("numeric", replicates)
set.seed(109)
for (k in 1:replicates) {
  draw <- sample(balls, 2, replace = FALSE)
  if (draw[1] == "W" & draw[2] == "R") successes[k] <- 1
}
mean(successes)

# Joint event
mean(child == 1 & gummy == 1)
```

## Summaries {#r-summaries}

| Setting | Code pattern |
|---------------------------|---------------------------------------------|
| One numerical variable | `dat |> summarize(mean_y = mean(y), sd_y = sd(y), n_y = n())` |
| Numerical **by two groups** | `dat |> group_by(group) |> summarize(n = n(), mean_y = mean(y), sd_y = sd(y))` |
| Counts for one categorical | `dat |> count(category) |> mutate(prop = n / sum(n))` |
| **2 × 2** counts | `dat |> count(group, outcome)` then `pivot_wider` |

------------------------------------------------------------------------

## Plots (ggplot2) {#r-plots}

| Setting | Pattern |
|-------------------------|-----------------------------------------------|
| **Numerical** response, **two groups** | `ggplot(dat, aes(x = group, y = y)) + geom_boxplot()` |
| **Two categorical** | `dat |> count(group, outcome) |> ggplot(aes(x = group, y = n, fill = outcome)) + geom_col()` |
| **Two numerical** | `ggplot(dat, aes(x = x1, y = x2)) + geom_point()` |
| **Subclassification** | Add `facet_wrap(~ confounder)` |

Always add **`labs(title = ..., x = ..., y = ...)`** with **units** where relevant.

------------------------------------------------------------------------

## Two-sample tests and confidence intervals {#r-tests}

| Response type | R command | Notes |
|-------------------------------|-----------------------|------------------|
| **Numerical**, 2 groups | `t.test(y ~ group, data = dat, var.equal = FALSE)` | Welch *t*-test; includes **95% CI** |
| **Binary**, 2 groups | `prop.test(x = c(x1, x2), n = c(n1, n2), correct = FALSE)` | Compares two **proportions** |
| Two categorical variables | `chisq.test(tab)` | Check **`chisq.test(tab)$expected`** for **≥ 5** rule |
