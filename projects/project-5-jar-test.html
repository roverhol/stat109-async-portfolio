# Stone jar weigher (prototype)

This is a prototype test page for the Project 5 data-collection tool. The jar below holds a fixed collection of stones whose individual weights are hidden. Enter how many stones you want to scoop, then click **Weigh** to see the total weight of a fresh random sample of that many stones (the empty container plus lid is included in every reading).

Record each `(number, total_weight)` pair by hand as you go. Later you will organize your readings into a spreadsheet, save it as a `.csv`, and upload it to Colab for analysis, just like collecting and tidying real data.

```{=html}
<div id="jar-widget" style="max-width:360px;margin:1em 0;padding:1em;border:1px solid #ddd;border-radius:8px;">
  <img src="project-5-figures/jar.png" alt="A glass jar filled with stones" style="width:100%;height:auto;border-radius:6px;">
  <div style="margin-top:0.75em;display:flex;gap:0.5em;align-items:center;flex-wrap:wrap;">
    <label for="jar-n">Number of stones to scoop:</label>
    <input id="jar-n" type="number" min="1" max="50" value="10" style="width:5em;">
    <button id="jar-go" type="button">Weigh</button>
  </div>
  <p id="jar-out" aria-live="polite" style="margin-top:0.75em;font-weight:600;min-height:1.4em;"></p>
</div>
<script>
(function () {
  const SUPABASE_URL = "https://pquheujodaapzinhemgr.supabase.co";
  const SUPABASE_ANON_KEY = "eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9.eyJpc3MiOiJzdXBhYmFzZSIsInJlZiI6InBxdWhldWpvZGFhcHppbmhlbWdyIiwicm9sZSI6ImFub24iLCJpYXQiOjE3ODIzMTA0NTQsImV4cCI6MjA5Nzg4NjQ1NH0.XGkHWVwRYzUrqeIraf84yxFKukhVrPWsJyuvD1TMPYk";
  const RPC_URL = SUPABASE_URL + "/rest/v1/rpc/weigh";

  const nInput = document.getElementById("jar-n");
  const goBtn = document.getElementById("jar-go");
  const out = document.getElementById("jar-out");

  goBtn.addEventListener("click", async function () {
    const n = parseInt(nInput.value, 10);
    if (!Number.isInteger(n) || n < 1) {
      out.textContent = "Please enter a whole number of stones (1 or more).";
      return;
    }
    goBtn.disabled = true;
    out.textContent = "Weighing...";
    try {
      const resp = await fetch(RPC_URL, {
        method: "POST",
        headers: {
          "apikey": SUPABASE_ANON_KEY,
          "Authorization": "Bearer " + SUPABASE_ANON_KEY,
          "Content-Type": "application/json"
        },
        body: JSON.stringify({ n: n })
      });
      if (!resp.ok) throw new Error("status " + resp.status);
      const total = await resp.json();
      out.textContent = n + " stones weigh " + total + " g.";
    } catch (err) {
      out.textContent = "Could not reach the scale. Check your connection and try again.";
    } finally {
      goBtn.disabled = false;
    }
  });
})();
</script>
```

## Setup note (remove before sharing with students)

The widget calls a Supabase `weigh(n)` RPC that samples a hidden weights table server-side. The project URL and anon public key are configured. The anon key is safe to embed publicly; the stone weights stay hidden because Row Level Security blocks reading the table directly, and only the `weigh()` function (which returns just a total) is callable.
:::
