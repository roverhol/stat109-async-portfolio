## What this checkpoint is for

This check lets you confirm your dataset loads before you invest time in graphs and the full report. Do not make univariate or bivariate plots, compute Pearson *r*, or write the one-page summary yet, those are Phase B.

### Why choose the dataset and variables before you plot?

In [Module 0, Read 0](../lectures/module-0-read-00), the five-step statistical process puts planning before collecting and after asking a question. This project is primary to work on your technical skill of making plots and calculating numerical summaries in R. So we'll ignore asking well-defined questions, a data collection plan and instead focus on a descriptive analysis, which is often the first stage of Step 4: Analyzing the Data.

| A3 | Run `glimpse()` and `head()` to confirm the file loaded (rows, columns, types). |
| A4 | From all columns in the dataset, choose four variables for Project 3. For each: name, description (from readme), type (categorical or numerical). |
